# 01: Fondasi reproduksibel jaringan kampus

**What to build:** Lingkungan proyek Jaringan Kampus dapat dinyalakan secara lokal, dengan konfigurasi dua gedung, daftar perangkat minimum, skema payload, dan satu perintah Docker Compose sebagai titik awal integrasi.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Docker Compose memuat layanan yang dibutuhkan tanpa konfigurasi cloud.
- [x] Konfigurasi mencakup dua gedung dan daftar 8 switch, 12 access point, serta 4 probe latensi.
- [x] Skema payload memuat identitas perangkat, jenis perangkat, gedung, timestamp, dan data.
- [x] README awal menjelaskan cara menyalakan dan menghentikan lingkungan dari nol.
